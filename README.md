# 本地多人德州扑克

## 运行

```bash
npm install
npm start
```

打开 `http://localhost:3000`。同一局域网内可用运行机器的 IP 加端口访问。

## 包含功能

- 用户名密码注册/登录（bcrypt 密码哈希、JWT 会话）
- SQLite 持久化用户积分、买入/返还流水、牌局快照与手牌日志
- WebSocket 实时同步，最多 6 人同桌，支持旁观
- 小盲/大盲、弃牌、过牌、跟注、加注、翻牌/转牌/河牌、七选五牌型比较和分池
- 响应式网页，兼容手机和桌面浏览器

这是本地演示项目，默认 JWT 密钥仅适用于开发；部署时请通过 `JWT_SECRET` 设置随机密钥并放在 HTTPS 反向代理后。
